Thunder-G

Layout

Hide the calendar pane, its splitter, and the bottom-right toggle. Applies immediately to all windows.

Turn this off to restore Thunderbird’s existing visibility setting. That setting is never changed.

Conversation reader

Off by default. Disable Thunderbird Conversations before enabling this experimental reader or inline replies: conversation handling is built into Thunder-G. Messages are grouped using Thunderbird's local index, with a folder-thread fallback when indexing is unavailable. Expand cards to read messages and attachments. Reply, Forward and Print use Thunderbird's native controls.

List columns, CSS, zoom and density stay native. Switching readers returns to the list. The toolbar above a conversation acts on the messages selected in the list, including when more messages are found in other folders.

Off by default. Starts a reply below the message with Thunderbird's native editor, preserving account signatures, recipients, formatting, attachments and native draft saving. Detach moves the same editor into a floating panel; its separate-window button saves the draft and opens it in Thunderbird's normal compose window. Forward keeps its usual window. An open reply stays available when navigating; close it before starting another reply. Turning this setting off affects new replies and keeps an existing draft open.

Sender logos

Optional remote image downloads — off by default. Enabling this contacts the logo host, which can see your IP address. After a successful aligned DKIM check, looks up the sender domain's BIMI DNS record and downloads only its HTTPS SVG logo. No logo directories, favicons or certificate downloads. A logo is a DNS-published image, not a certified identity badge.

Contact photos take priority. Missing or invalid records leave the existing avatar unchanged. Logos and missing results are cached for one hour during this session to avoid repeat requests. Turning this off stops new downloads and restores the usual avatars immediately. Applies immediately.

Compose and drafts

Enabled by default, every minute. Uses each account's configured Drafts folder and Thunderbird's native autosave. Changes apply to newly opened compose windows. Disabling Thunder-G restores previous Thunderbird settings unless changed independently.

Message list

Global setting, saved across restarts. Uses the original list, columns and density. Collapsed conversations count as one row. Ctrl/Cmd + plus, minus and zero use Thunderbird's interface font controls outside text fields.
